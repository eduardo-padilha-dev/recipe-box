# Smart Recipe Box

Laboratório individual da Atividade 09 para aprender Angular moderno com fundamentos, Signals e arquitetura de componentes.

## Desenvolvimento

Instale as dependências e inicie o servidor local:

```bash
npm install
npm start
```

A aplicação fica disponível em `http://localhost:4200/`.

## Testes e build

```bash
npm test -- --watch=false
npm run build
```

O projeto usa componentes standalone, Signals, `@if`, `@for`, bindings nativos e dados locais. Serviços, rotas, formulários, persistência e backend estão fora do escopo desta etapa.
